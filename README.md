# AR Inhaler Coaching Prototype

## Overview

A learning prototype exploring Augmented Reality based
inhaler coaching using Unity and AR Foundation.

## Features

- AR plane detection
- Virtual inhaler placement
- Step-by-step coaching instructions
- Spatial interaction
- Visual feedback

## Technologies

- Unity
- C#
- AR Foundation
- ARCore

## Project Relevance

This prototype explores AR interaction concepts relevant to
the Shwaas AR Enhanced project, particularly guided inhaler
training and visual coaching.
